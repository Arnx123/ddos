# Anti-DDoS Protection System

Kompletní anti-DDoS systém s admin panelem podporující L3, L4, L7 ochranu a geoblokaci.

## 🚀 Funkce

- **L3/L4/L7 DDoS ochrana** s eBPF/XDP
- **Dva typy uživatelů** (Owner + Subuser)
- **Real-time monitoring** útoků
- **Geoblokace** zemí
- **Firewall režimy** (Accept/Filter/Drop)
- **Správa portů** TCP/UDP
- **Supabase integrace**
- **Moderní tmavý design**

## 📦 Technologie

- Next.js 14 + TypeScript
- Express.js backend
- eBPF/XDP packet filtering
- Supabase database
- Tailwind CSS
- Socket.io
